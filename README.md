# 王国崛起

网页优先的 2D RTS 与领地经营原型。项目当前处于 V0.2 稳定性收尾阶段，已支持多角色独立操作、连续坐标移动、障碍绕行、资源采集、自动运输和仓库交付。

当前版本范围与后续里程碑见 [《王国崛起》开发版本规划 V2.0](docs/王国崛起_开发版本规划_V2.0.md)。[V0.1 当前开发总结](docs/王国崛起_V0.1当前开发总结.md)保留为带日期的历史快照，不再代表当前版本划分。

## 开发命令

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

## 模块边界

- `src/core`：纯 TypeScript 游戏规则，不依赖 Phaser 或 DOM。
- `src/presentation`：Phaser 场景与绘制，只读取核心状态。
- `src/main.ts`：浏览器入口与引擎配置。
- `tests`：不启动浏览器的核心规则测试。

全局路径由 PathFinding.js 计算，bitECS 保存并推进单位状态。V0.2 的 `AvoidanceSystem` 仍使用直通实现；基础单位分离避让属于 V0.3，具体方案在进入该版本时再评估。

## 操作

- 左键点击领袖或居民选择；点击空白处取消选择。
- 选中角色后左键点击资源点，角色会自动采集、装满、送回仓库并循环工作；采集任务的往返路线默认不显示。
- 选中后右键点击任意可通行位置；空旷时直线移动，有障碍时自动绕行并抵达准确点击位置。
- 按住鼠标中键拖动地图，滚轮缩放。
- Developer Console 默认以可拖拽悬浮球显示，可展开或收起；控制台可暂停、单步和倍速运行模拟，动态生成居民或编辑障碍，并观察 ECS、命令、寻路、碰撞和渲染状态。
- 内置双人采集、障碍绕路、仓库边界和完全阻断四个可重复验证场景；恢复初始世界不需要刷新页面。

V0.2 暂不包含群体选择、动态单位避让、多资源生产链、建筑、NPC AI、战斗、存档、网络和正式美术。
